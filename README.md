# Agent Note CLI

Turn local AI coding sessions into a clear daily work brief.

Agent Note CLI is the open-source command-line companion to Agent Notebook, built for developers who work in the terminal and want to understand what they and their agents accomplished.

## Status

Early development. This repository currently contains project documentation; there is no installable CLI yet.

## Initial scope

- Read local Codex and Claude Code session records.
- Summarize work by project and workstream, including progress and unfinished work.
- Preserve source references and make missing or failed evidence visible.
- Support terminal output, Markdown, and JSON for scripting.
- Use the user's own model configuration, with clear disclosure of what is sent to a model service.

The CLI focuses on the daily brief. The desktop app provides the broader visual workspace for reflection and long-term knowledge management.
